PathFinder AI 🎓

AI-powered academic and career orientation platform for Moroccan students.

📌 About the Project

PathFinder AI is an intelligent orientation platform designed to help Moroccan students make informed decisions about their academic and professional futures after the baccalaureate.

Through an interactive AI-powered chatbot, the platform analyzes students' academic results, interests, skills, preferences, and career goals to suggest suitable educational pathways and institutions.

🎯 Objectives

- Understand each student's academic and personal profile.
- Recommend suitable fields of study and academic programs.
- Provide personalized and explainable recommendations.
- Present reliable information about Moroccan institutions and programs.
- Help students explore potential career opportunities.

✨ Main Features

- Interactive AI chatbot.
- Adaptive student questionnaire.
- Student profile analysis.
- Personalized recommendation engine.
- Ranked academic program recommendations.
- Explanations for each recommendation.
- Moroccan educational programs and institutions catalogue.

🚀 Project Workflow

The project follows a collaborative GitHub workflow:

1. Each team member works on their own feature branch.
2. Changes are committed and pushed to GitHub.
3. A Pull Request is created to propose changes.
4. Changes are reviewed before being merged into `main`.
